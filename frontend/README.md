# Фронтенд — Карта Ликвидности

Telegram Web App на **Vue 3 (Options API)** + **Vite**. Собирается и запускается
отдельным сервером от бэкенда.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

```bash
npm run build    # сборка в dist/
npm run preview  # предпросмотр собранной версии
```

## Структура

```
src/
  main.js                 # точка входа, подключает роутер и стили
  App.vue                 # мобильный кадр 393×856 + нижняя навигация
  router/index.js         # маршруты шести экранов
  styles/
    tokens.css            # дизайн-токены из Figma (цвета, шрифты, радиусы)
    fonts.css             # @font-face для Kreadon / Min Sans (файлы добавить)
    base.css              # сброс и базовые стили
  components/
    BottomNav.vue         # плавающая нижняя навигация
    ScreenPlaceholder.vue # заглушка экрана
    icons/                # иконки (inline SVG)
  views/                  # по одному файлу на экран (пока заглушки)
```

## Экраны

Каждый экран верстается по макету Figma (страница «Дизайн») в отдельном PR:

| Маршрут              | Экран                   |
| -------------------- | ----------------------- |
| `/login`             | Вход и регистрация      |
| `/password-recovery` | Восстановление пароля   |
| `/home`              | Главная                 |
| `/analytics`         | Аналитика отчёты        |
| `/community`         | Сообщество              |
| `/profile`           | Профиль                 |

## Связь с бэкендом

Бэкенд (Laravel) поднимается на `http://localhost:8000`. В dev-режиме запросы к
`/api` проксируются на него через `vite.config.js`.

## Шрифты

Макет использует **Kreadon** (заголовки) и **Min Sans** (основной текст) — платные
шрифты, их файлов в репозитории нет. Положите лицензионные `.woff2` в
`src/assets/fonts/` и раскомментируйте `@font-face` в `src/styles/fonts.css`.
До этого работает системный фолбэк.
