# Как собрать и запустить приложение на Windows (через эмулятор)

Android-приложение собирается не в `.exe`, а в `.apk` — установочный файл Android.
На Windows его запускают в эмуляторе Android. Ниже — полный путь «из кода → потыкать».

## 1. Поставить инструменты (один раз)

1. Скачай и установи **Android Studio**: https://developer.android.com/studio
   (внутри уже идут JDK, Android SDK и эмулятор — отдельно ничего ставить не нужно).
2. При первом запуске мастер докачает SDK — просто соглашайся.
3. В Windows должна быть включена аппаратная виртуализация (VT-x / AMD-V в BIOS),
   иначе эмулятор будет сильно тормозить. На современных ПК обычно включена.

## 2. Указать адрес бэкенда (обязательно)

Адрес API «зашивается» в сборку через параметр `API_BASE_URL` — он **должен
оканчиваться на `/api/`**. По умолчанию там заглушка `https://karta.example.com/api/`,
с ней данные грузиться не будут.

Открой файл `android/gradle.properties` и добавь строку с реальным адресом:

- **Бэкенд развёрнут на сервере с HTTPS:**
  ```properties
  API_BASE_URL=https://твой-домен/api/
  ```
- **Бэкенд крутится локально на этом же ПК** (`php artisan serve`, порт 8000):
  из эмулятора твой компьютер виден по адресу `10.0.2.2` (а не `localhost`):
  ```properties
  API_BASE_URL=http://10.0.2.2:8000/api/
  ```
  Незашифрованный `http` в debug-сборке уже разрешён (см. `app/src/debug/AndroidManifest.xml`),
  так что локальный бэкенд заработает.

На стороне Laravel: убедись, что CORS/хост не режет запросы (настройка `.env`,
код бэкенда менять не нужно).

## 3. Собрать APK

**Через Android Studio (проще):**
1. `File → Open` → выбери папку **`android`** из репозитория (именно её, не корень).
2. Дождись окончания Gradle sync.
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
4. Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`.

**Или из командной строки** (в папке `android`):
```bat
gradlew.bat assembleDebug
```
(адрес бэка возьмётся из `gradle.properties`, либо передай его прямо:
`gradlew.bat assembleDebug -PAPI_BASE_URL=https://твой-домен/api/`)

## 4. Запустить в эмуляторе

1. В Android Studio: `Tools → Device Manager → Create Device`.
2. Выбери, например, **Pixel 7**, образ системы **Android 14 (x86_64)** → `Finish`.
3. Запусти эмулятор кнопкой ▶ в Device Manager.
4. Нажми зелёный **Run ▶** в Android Studio (с выбранным эмулятором) — он сам
   соберёт, установит и откроет приложение.

Альтернатива для установки готового APK: перетащи `app-debug.apk` в окно
эмулятора, либо выполни `adb install app-debug.apk`.

## Быстрый вариант «только посмотреть интерфейс»

Каждая сборка на CI (GitHub Actions) кладёт готовый `app-debug.apk` в артефакт
`app-debug` — его можно скачать и поставить в эмулятор без локальной сборки.
Но он собран с заглушкой-URL, поэтому реальные данные с бэкенда грузиться не
будут — только интерфейс. Для работы с данными собирай сам с реальным
`API_BASE_URL` (шаг 2).
